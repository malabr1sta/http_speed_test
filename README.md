# Измерение скорости скачивания

Консольный скрипт на Python без сторонних зависимостей. Делает 10 последовательных GET-запросов к указанному HTTP(S)-адресу, каждый раз дожидаясь полного тела ответа. Файлы на диск не сохраняются: данные читаются порциями по 64 КиБ.

## Запуск

Нужен Python 3.8 или новее. Скачайте файлы репозитория и откройте терминал в их папке.

```bash
python speed_test.py "https://example.com/large-image.jpg"
```

Замените адрес на прямую ссылку на доступный файл. На Linux/macOS при необходимости используйте `python3`, на Windows — `py`.

Необязательный тайм-аут сетевой операции (по умолчанию 30 секунд):

```bash
python speed_test.py "https://example.com/large-image.jpg" --timeout 60
```

Справка:

```bash
python speed_test.py --help
```

## Результаты и единицы измерения

Для каждого запроса выводятся время в секундах и количество полученных байтов. После 10 успешных запросов выводятся:

- Среднее время запроса: сумма времён / 10, в секундах.
- Общий объём: сумма полученных тел ответов, в байтах и МиБ (1 МиБ = 1 048 576 байт).
- Средняя скорость скачивания: общий объём в байтах × 8 / сумму времён / 1 000 000, в Мбит/с (1 Мбит = 1 000 000 бит).

Скорость вычисляется из суммарного объёма и суммарного времени, а не как среднее арифметическое скоростей отдельных запросов.

Замер через `time.perf_counter()` включает установление соединения, ожидание ответа, переходы по HTTP-редиректам и чтение полного тела конечного ответа. Вывод в консоль между запросами в измерение не входит. Объём учитывает тела конечных ответов, без заголовков и сетевых накладных расходов. Скрипт запрашивает ответ без сжатия (`Accept-Encoding: identity`).

Это скорость получения данных от конкретного сервера: на неё влияют задержки, сервер и маршрут соединения. Она не обязательно равна максимальной пропускной способности интернета. Для измерения лучше использовать большой файл; он будет загружен десять раз.

## Ошибки

При сетевой ошибке, HTTP-ошибке или обнаруженном обрыве ответа скрипт печатает причину в stderr и завершается с кодом 1. Итоги неполной серии не выводятся. Некорректные аргументы дают код 2, прерывание Ctrl+C — 130, успешное выполнение — 0.

Тайм-аут относится к отдельным блокирующим сетевым операциям, а не ко всему скачиванию. Когда сервер не передаёт длину тела и не использует chunked-кодирование, отличить корректное закрытие соединения от обрыва средствами HTTP невозможно.
